For a faster answer

Most problems can be solved in one reply when the first message includes:

  • The pack name and version, as shown in the Package Manager
  • Your Unity version and render pipeline (URP, Built-in or HDRP)
  • What you expected and what happened instead
  • A screenshot, and the Console message if there is one
  • Your invoice number if the question is about a purchase
